# HTML Text Formatting

## Explanation

This program demonstrates different text formatting elements available in HTML.

These elements are used to change the appearance or meaning of text displayed on a webpage.

## Problem Statement

Create an HTML webpage that demonstrates commonly used text formatting tags.

## Features

- Displays bold text
- Displays italic text
- Displays underlined text
- Highlights text
- Displays deleted and inserted text
- Demonstrates subscript and superscript

## How It Works

The program uses different HTML formatting elements to display text in different styles.

For example:

<b> creates bold text.

<i> creates italic text.

<mark> highlights text.

<sub> creates subscript text.

<sup> creates superscript text.

## Technologies Used

- HTML5

## HTML Tags Used

- <b> - Bold text
- <strong> - Important text
- <i> - Italic text
- <em> - Emphasized text
- <u> - Underlined text
- <mark> - Highlighted text
- <small> - Smaller text
- <del> - Deleted text
- <ins> - Inserted text
- <sub> - Subscript text
- <sup> - Superscript text
